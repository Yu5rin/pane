## 1. Paneとは何か

Paneは、**Markdownで書いたメモを、記号だらけの生テキストのままではなく、実際に整形された文章として見ながら書ける**、Windows向けのデスクトップメモ帳アプリです。

`# 見出し`と打てば大きな見出しの文字に、`**太字**`と打てばその場で太字に変わります。ここが普通のテキストエディタと大きく違う点で、書いている最中にどう仕上がるかが常に見えます。しかも記号は書いた瞬間に消えてなくなるわけではありません。**カーソルが乗っている行だけ**、`**`や`#`といった元の記法がそのまま見える生の表示に戻ります。だから「どう書けばこの見た目になるのか」を見失わず、後から記法だけを直したいときも迷いません。他の行は整形された見た目のままなので、文書全体としては常に読みやすい状態を保てます。

Markdown用のメモ帳という側面に加えて、`.js` `.py` `.cs` `.json`など**コードファイルを開くと、行番号付き・シンタックスハイライト付きのコードエディタとしても使えます**(第4章)。これはTypora等のMarkdownエディタには無い、Pane独自の拡張です。日々のメモ帳としても、ちょっとしたコードやログファイルを覗く道具としても、この1本のアプリで済ませられます。

どういう場面で役に立つかというと、たとえば次のような使い方です。

- 会議の議事録や日報を、箇条書き・チェックリスト・表を使いながら素早く書く
- 技術メモやREADMEの下書きを、実際にどう表示されるか確認しながら書く
- ソースコードやログファイルを、色分けされた読みやすい状態でさっと確認する
- 何百行もあるMarkdown文書を、サイドバーの見出し一覧(アウトライン)から目的の場所へすぐジャンプする

Paneが外部と通信するのは**新しい版があるかを尋ねるときだけ**です(第8章・第9章)。使用状況の送信も、テーマや辞書のダウンロードもなく、**書いた内容やファイルの中身が手元の外へ出ることは一切ありません**。更新の確認は起動したあとに行い、設定でオフにもできます。新しい版が見つかってもお知らせするだけで、**断りなくPaneが書き換わることはありません**。

## 2. 最初の5分

1. **起動する**
   Paneを起動すると、設定(第7章「一般」)に応じて、空の新規文書、前回開いていたファイル、またはあらかじめ指定したフォルダのいずれかが開きます。
2. **Markdownで書いてみる**
   本文へそのまま入力を始めます。行頭に`# `と打てば見出しに、`**強調したい語**`と打てばその場で太字になります(第5章に記法の一覧があります)。
3. **ライブプレビューを確かめる**
   打った記号がその場で整形され、カーソルを別の行へ移すと記法の記号は隠れて文章として読みやすい見た目になります。もう一度その行にカーソルを戻すと、記法がそのまま見える表示に戻ります。
4. **保存する**
   Ctrl+Sを押します。まだ一度も保存していない文書なら、保存先を選ぶダイアログが開きます。既定の拡張子は`.md`です。
5. **そのまま書き続ける**
   既定では30秒ごとに自動保存が働くため(第4章・第7章)、Ctrl+Sを毎回意識しなくても、書きかけの内容が失われにくくなっています。

慣れてきたら、メニューバーの「段落」「書式」から見出し・表・引用・リストなどをボタンで挿入したり、コマンドパレット(Ctrl+Shift+P、第4章)から操作名を検索して実行したりすると、キーボードだけで手早く書き進められます。

## 3. 画面の説明

Paneの画面は、上から順にタイトルバー・メニューバー・本文エリア(必要に応じて左にサイドバー)・ステータスバーの構成です。

### 3.1 メニューバー

「ファイル」「編集」「段落」「書式」「表示」の5つのメニューが並びます。既定で常に表示されており、Altキーを押すたびに表示・非表示を切り替えられます(表示中はショートカットキーの一覧としても使えます)。右端には、ライトテーマとダークテーマを切り替えるボタン、設定を開くボタン(Ctrl+,)、ヘルプを開くボタンがあります。

### 3.2 本文エリア

文書を編集する中央の領域です。開いているファイルの種類に応じて、Markdownのライブプレビュー・シンタックスハイライト付きのコード表示・装飾のないプレーンテキスト表示のいずれかで表示されます(表示メニューからいつでも手動で切り替えることもできます)。

### 3.3 サイドバー

Ctrl+Shift+L(またはステータスバー左端のボタン)で開閉します。上部の3つのタブで表示内容を切り替えます。

- **アウトライン**(Ctrl+Shift+1): 現在の文書の見出し(#〜######)を階層付きの一覧にして表示します。クリックすると本文の該当箇所へ移動します。
- **ファイル**(Ctrl+Shift+2): 最近開いたファイルを新しい順に一覧表示します。クリックするとそのファイルを開きます。
- **ファイルツリー**(Ctrl+Shift+3): 現在のファイルの親フォルダ(またはメニューの「フォルダを開く」で明示的に開いたフォルダ)の中身を、階層構造のまま一覧表示します。ここから全文検索(第4章)も行えます。

サイドバーの右端をドラッグすると幅を変えられ(ダブルクリックで既定幅に戻ります)、変えた幅は次回起動時にも覚えています。

### 3.4 ステータスバー

画面いちばん下の帯です。左からサイドバー開閉ボタン、編集モード(Markdown/コード/プレーンテキスト。コードモードのときはクリックで言語を選び直せます)、カーソルの行・列位置、文字コード、改行コード、折り返し表示のオン/オフ、文字数(クリックで単語数・行数・段落数・読了時間の詳細を表示)、拡大率(クリックで100%に戻します)が並びます。表示するかどうかは設定で切り替えられます。

## 4. 主な機能

### 4.1 ライブプレビュー

Markdownの記法を、記号のまま表示するのではなく実際に整形して表示します。見出し・強調・リスト・表・コードブロックなどはその場で見た目が変わり、生の記法が見えるのはカーソルのある行だけです(設定「編集」の「カーソル行の生表示」でオン/オフできます)。書きながら仕上がりを確認できるため、後から別のプレビュー画面を開き直す必要がありません。

### 4.2 タブ/ウィンドウ形式

既定では、ファイルを開くたびに独立したウィンドウが開く「ウィンドウ形式」です(表示メニューの「開いている文書を切り替え」Ctrl+Tabで、開いている文書間を移動できます)。1つのウィンドウの中にタブを並べる「タブ形式」も実装されていますが、切り替え用のボタンは設定画面には用意されておらず、切り替えるには設定ファイル(第9章)を直接編集する必要がある上級者向けの機能です。既定のウィンドウ形式のままであれば、この点を意識する必要はありません。

### 4.3 サイドバー(アウトライン・ファイルツリー・全文検索)

第3.3節のとおり、見出し一覧・最近使ったファイル・フォルダのツリー表示を切り替えて使えます。ファイルツリーを開いている(=フォルダを読み込んでいる)状態では、Ctrl+Shift+Fでそのフォルダ配下を横断する全文検索も行えます。検索対象から除外するファイル・フォルダのパターン(`node_modules/`など)は設定「詳細」で指定できます。

### 4.4 コマンドパレット

Ctrl+Shift+Pで開きます。メニューバーの「ファイル」「編集」「段落」「書式」「表示」にある操作をまとめて名前で検索し、その場で実行できます。ボタンの場所やショートカットキーを覚えていなくても、操作名の一部を入力するだけで見つけられます。

### 4.5 検索と置換

Ctrl+Fで文書内検索、Ctrl+Hで置換パネルを開きます。入力するたびにその場でハイライトされ、F3/Shift+F3で次/前の一致箇所へ移動します。「Aa」(大文字・小文字を区別)、「単語」(単語単位での完全一致)、「.*」(正規表現。置換後の文字列では`$1`のようにキャプチャグループを参照可能)をそれぞれオン/オフできます。

### 4.6 自動保存と復元

設定「ファイル」の「自動保存」をオンにしている間(既定オン)、指定した間隔(既定30秒、5〜600秒で調整可)ごとに編集中の内容が自動でスナップショットとして書き出されます。Paneが強制終了やクラッシュなどで正常に終了できなかった場合、次回起動時に「前回のPaneは正常に終了しませんでした。未保存の内容を復元しますか?」という確認が表示され、「はい」を選ぶと直前の状態から書き直せます(この確認自体は設定「ファイル」の「未保存の下書きを復元」でオフにもできます)。

### 4.7 エクスポート(PDF・HTML等)

メニュー「ファイル」から、現在の文書を次の形式で書き出せます。

| 形式 | 備考 |
|---|---|
| PDF | 外部ソフト不要。ライブプレビューの見た目をそのまま出力します |
| HTML | 見た目を再現するスタイル付きの単一ファイル |
| HTML(スタイルなし) | 装飾を持たない素のHTML |
| Word / EPUB / RTF / LaTeX / Textile | **Pandocが導入された環境でのみ利用できます**(下記) |

用紙サイズ・余白・ヘッダー/フッターの文字列などは設定「エクスポート・印刷」で細かく指定でき、PDFエクスポートに適用されます。Word以下の5形式は内部でPandocという外部ツールを呼び出しており、Pandoc自体がインストールされていない環境ではメニュー上でグレーアウトして選べません(第8章「既知の制限」)。

### 4.8 印刷

メニュー「ファイル」→「印刷」(Ctrl+Alt+P)から、WindowsのネイティブなプリンターダイアログでPCに接続されたプリンターへ印刷できます。**用紙サイズ・余白・ヘッダー/フッターといった設定「エクスポート・印刷」の詳細項目は、この印刷経路には反映されません**(それらが適用されるのはPDFエクスポートのみです)。凝った紙面で印刷したい場合は、一度PDFへエクスポートしてからそのPDFを印刷してください。

### 4.9 テーマ

設定「外観」から、画面全体をライト/ダーク/システム(Windowsの設定に追従)のいずれかにできます。ライト用・ダーク用それぞれに、既定に加えて何種類かの配色プリセット(セピア、GitHub風、Solarized、Nord、Draculaなど)から選べ、ライト/ダークで別のプリセットを使うことも、同じものを使うこともできます。メニューバー右端のボタンでもその場で手動切り替えができます。さらに凝った配色にしたい場合は、カスタムCSSファイルを指定して見た目を細部まで自作することもできます(既定の保存場所に、書き方の説明が入ったサンプルCSSが用意されています。第9章)。

### 4.10 コードモード

`.js` `.py` `.cs`など約60種類のプログラミング言語・スクリプト・マークアップ・データ形式に対応したシンタックスハイライトで開けます。行番号ガター、対応する括弧の強調表示、カーソルのある行の淡いハイライト、インデントの深さを示す縦線(インデントガイド)、コード中に書かれた色コード(`#ff0000`など)へのスウォッチ表示(カラープレビュー)を備えます。関数・オブジェクト・配列などのまとまりは折りたたんで隠せます(Alt+[で折りたたみ、Alt+]で展開。表示メニューには、レベル指定での一括折りたたみやコメントブロックの折りたたみなど、さらに細かい操作もあります)。フェンス付きコードブロック(```` ``` ````)の右上にはコピー用のボタンが出て、行番号を含まずに中身だけをクリップボードへコピーできます。

### 4.11 画像の貼り付け

画像は次の3つの方法で挿入できます。

- メニュー「書式」→「画像」(Ctrl+Shift+I)でファイルを選ぶ
- クリップボードにコピーした画像をCtrl+Vで貼り付ける
- 画像ファイルを本文へドラッグ&ドロップする

設定「画像」の「画像の保存方法」で、挿入した画像を文書と同じフォルダ・`assets`フォルダ・文書名と同じ名前の専用フォルダ・任意のカスタムフォルダのいずれかへコピーするかどうかを選べます(既定は「コピーしない」)。文書からの相対パスで書き込むか絶対パスにするかも選べます。なお`https://`のようなオンライン画像はダウンロードして手元に保存する機能を持ちません(外部通信を行わない方針のため。第8章)。クリップボードに画像そのものがある場合(スクリーンショット等)は通信を伴わないため、通常どおりローカルへ保存できます。

## 5. Markdown記法の書き方

Paneが対応するMarkdown記法の一覧です。多くはGitHub Flavored Markdown(GFM)に準拠しています。一部の記法は設定「Markdown」でオン/オフを切り替えられます(第7章)。

### 5.1 基本記法

| 書き方 | 表示 |
|---|---|
| `# 見出し1` 〜 `###### 見出し6` | 6段階の見出し(Ctrl+1〜6で付け外し) |
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `<u>下線</u>` | 下線付きの文字 |
| `` `インラインコード` `` | 地の文中のコード表示 |
| `~~取り消し線~~` | 取り消し線 |
| `==ハイライト==` | 蛍光ペンで塗ったような強調(設定でオン/オフ) |
| `x^2^` | 上付き文字(設定でオン/オフ) |
| `H~2~O` | 下付き文字(設定でオン/オフ) |

### 5.2 リストと引用

| 書き方 | 表示 |
|---|---|
| `- 項目` または `* 項目` | 箇条書きリスト |
| `1. 項目` | 番号付きリスト |
| `- [ ] 未完了のタスク` | クリックで完了に切り替えられるチェックボックス |
| `- [x] 完了したタスク` | チェック済みタスク(取り消し線付きで表示) |
| `> 引用文` | 左に縦線が付く引用ブロック(`>>`で入れ子も可) |

### 5.3 表とコードブロック

| 書き方 | 表示 |
|---|---|
| `\| 見出しA \| 見出しB \|`<br>`\|---\|---\|`<br>`\| セル \| セル \|` | 罫線付きの表。列幅はドラッグで調整可能 |
| 3つのバッククォートで言語名を添えて囲む(例: `` ```js ``) | 言語別に色分けされたコードブロック。行番号表示・コピーボタン付き |

### 5.4 区切りとリンク

| 書き方 | 表示 |
|---|---|
| `---`(3つ以上のハイフン) | 水平線 |
| `[表示文字](URL)` | ハイパーリンク |
| `[表示文字][id]` と別の行に `[id]: URL` | 参照形式のリンク |
| `<https://example.com>` | そのままリンクになる自動リンク |
| `[見出しへ](#見出しの文字列)` | 同じ文書内の見出しへジャンプする内部リンク(Ctrl+クリックで移動) |

### 5.5 画像と脚注

| 書き方 | 表示 |
|---|---|
| `![代替テキスト](パス)` | 画像(第4.11節の方法で挿入すると自動で書かれます) |
| 本文中に `文中の一言[^1]`、別の場所に `[^1]: 注釈の内容` | 脚注番号を振り、番号にマウスを乗せると内容がポップアップ表示されます |

### 5.6 その他の拡張記法

| 書き方 | 表示 |
|---|---|
| `[toc]` | その文書の見出しから自動生成される目次。見出しの増減に自動で追従します |
| `> [!NOTE]`<br>`> 本文` | 種類ごとに色分けされた注釈枠(Callouts)。`NOTE`/`TIP`/`IMPORTANT`/`WARNING`/`CAUTION`の5種類に対応(設定でオン/オフ) |
| `:smile:` のような記法 | 絵文字(😄)に変換されます。`:`を打つと候補が補完表示されます(設定で自動補完のオン/オフ・タイミングを調整可) |
| `$E=mc^2$` | 文中に埋め込むインライン数式(設定でオン/オフ) |
| 独立した行の `$$` から次の `$$` までの間 | 独立したブロック数式(MathJaxで描画。mhchem・AMSmath・BBoxの拡張構文にも対応) |
| ` ```math ` で始まるコードブロック | ブロック数式の別の書き方(設定でオン/オフ) |
| ` ```mermaid ` で始まるコードブロック | フローチャートやシーケンス図などのMermaid図として描画 |
| 文書の先頭を `---` と `---` で挟む | YAML形式のメタ情報(Front Matter)。エクスポート時のタイトル等に利用されます |

## 7. 設定

設定画面はメニュー「ファイル」→「設定」、またはCtrl+,、メニューバー右端の設定ボタンから開きます。左側にカテゴリの一覧、右側に選んだカテゴリの項目が並びます。上部の検索欄にキーワードを入れると、該当するカテゴリだけに絞り込めます。カテゴリは次の11個です。

### 一般

起動時の動作(何も開かない/前回のセッションを復元する/指定したフォルダを開く)、最後のウィンドウを閉じたときに常駐させておくか、ステータスバーの表示、最近使ったファイルの記録、Ctrl+マウスホイールでの拡大縮小、ツールチップ(マウスを乗せたときに出る説明)の詳しさ(表示しない/最低限/標準/詳しい)などを設定します。

### ファイル

自動保存の有効/無効と間隔(既定30秒、5〜600秒)、未保存の下書きを復元するか(第4.6節)、新規文書の既定の文字コード・改行コード・拡張子を設定します。

### 編集

インデント幅、コードモードのインデント幅・インデントガイドの表示範囲・折りたたみの有効/無効・現在行の強調・長い行の折り返し、コード中の色コードのスウォッチ表示(カラープレビュー)、括弧やMarkdown記法(`**`など)の自動補完、絵文字の自動補完、コピー時の既定の形式(Markdown/HTML)、スペルチェックの有効/無効などを設定します。

### Markdown

インライン数式・上付き/下付き・ハイライト・作図(Mermaid)・自動リンク・Callouts(GitHub式アラート)の記法ごとのオン/オフ、厳格モード(崩れた書き方を記法として認識しない)、見出しやリストをメニューから作るときの記法(ハイフン/アスタリスク等)、コードブロックの行番号表示、数式の自動採番、アウトラインに表示する見出しの深さなどを設定します。

### 画像

第4.11節の保存方法(コピーしない/文書と同じフォルダ/`assets`フォルダ/文書名フォルダ/カスタムフォルダ)、相対パス/絶対パスの優先、パスの先頭に`./`を付けるか、パスのURLエスケープを設定します。

### エクスポート・印刷

用紙サイズ・向き・余白、ヘッダー/フッターの文字列(`{title}` `{page}` `{date}`などが使えます)、見出しごとのページ区切り、書き出したファイルを開くかどうかなど、PDFエクスポート(第4.7節)に関する項目をまとめて設定します。

### 外観

テーマ(ライト/ダーク/システム)、ライト用・ダーク用それぞれの配色プリセット、カスタムCSSファイルの指定、フォント(本文用・等幅用)とサイズ・行の高さ・本文の左右の余白、ステータスバーの文字数表示のオン/オフを設定します。

### ファイルの関連付け

エクスプローラーで各拡張子のファイルをダブルクリックしたときにPaneで開くようにするかどうかを、拡張子ごとにチェックボックスで選べます(第8章「関連付けを解除したいとき」も参照)。

### キーボード

各コマンドのショートカットキーを、既定から別の組み合わせへ変更できます(第6章末尾も参照)。

### 詳細

開発者ツール(Shift+F12)を使えるようにするか、**詳細ログを記録するか**、ファイルツリーで隠しファイルを表示するか、全文検索・ファイルツリーの対象から除外するパターン、コマンドラインからPaneを起動できるようにするか(PATHへの登録)を設定します。設定ファイルの場所を開く・すべて既定に戻す・最近使ったファイルの履歴を消す、といったボタンもここにあります。

「詳細ログを記録する」は、普段は記録していない細かい動き(メニュー操作、画面の更新など)まで残す設定です。不具合の報告を求められたときだけ有効にしてください。有効にするとログが読みにくくなりますが、**動作が遅くなることはありません**(ログの書き込みは裏でまとめて行われます)。

### バージョン情報

Paneやランタイムのバージョン、ログフォルダ・カスタムCSSフォルダを開くボタン、使用しているOSSライブラリのライセンス表記を確認できます(第8章「不具合の調査に協力する」も参照)。

#### 新しい版があるか調べる

同じ画面の「更新」にある**「更新を確認」ボタン**を押すと、配布元(GitHub)に新しい版があるかどうかを尋ねます。

その上にある**「起動時に新しい版があるか確認する」**をオンにしておくと(既定でオン)、起動するたびに同じ確認を自動で行います。新しい版が見つかったときは画面上部の帯でお知らせします。帯の「更新する」を押すとこの画面が開きます。**お知らせするだけで、断りなく更新することはありません。**

起動時の確認が不要なら、このチェックを外してください。外すと「更新を確認」ボタンを押したとき以外は通信しなくなります(第8章「外部通信について」)。

新しい版があった場合は「更新する」ボタンが出ます。押すと確認のうえでダウンロードし、Paneを新しいものに入れ替えて再起動します。次の場合は自動で入れ替えられないため、代わりに「リリースページを開く」から手元にダウンロードして、展開したファイルを差し替えてください。

- 保存していない文書があるとき(入れ替えには再起動が必要です。先に保存してください)
- `Program Files`など、書き込みに管理者権限が要る場所にPaneを置いているとき

入れ替えの途中で失敗した場合は、元のPaneがそのまま残ります。

## 8. 困ったときは

### 文字化けして見える

ステータスバーの文字コード表示をクリックすると、現在のファイルとして扱う文字コード(UTF-8・UTF-8(BOM付き)・UTF-16 LE・Shift_JIS)を選び直せます。開いたときの文字コードは自動判定されて保持されるため、通常は変更の必要はありませんが、判定を誤った場合はここから選び直し、必要なら保存し直してください。新規文書の既定の文字コードは設定「ファイル」で変更できます。

### ファイルが開けない・編集できない

10MBを超える大きなファイルは、動作を軽くするためライブプレビューを自動的に無効化し、プレーンテキストとして開きます。また、読み取り専用属性が付いたファイルは編集できない状態で開き、上書き保存しようとすると警告が表示されます。

### 書きかけの内容が消えてしまった

自動保存(第4.6節)が有効になっていれば、Paneが正常に終了できなかった次回の起動時に復元の確認が表示されます。「いいえ」を選んで復元を見送ってしまった場合、そのスナップショット自体は失われるため元には戻せません。日頃からCtrl+Sでこまめに保存することをおすすめします。

### 起動しない

Paneは同時に多重起動しない設計です。既に起動している状態でもう一度Paneを起動しようとすると、新しいプロセスは何もせずに終了し、既存のPaneへ新しいウィンドウとして開く指示だけが伝わります(起動していないように見えても、既存のウィンドウが裏で開いているだけの場合があります。タスクバーを確認してください)。それでも起動しない場合、Paneの表示にはMicrosoft製のWebView2ランタイムが必要です。Windows Updateを最新にするか、WebView2ランタイムが導入されているか確認してください。

### 関連付けを解除したい

設定「ファイルの関連付け」で、関連付けたい(または解除したい)拡張子のチェックを外して保存します。Windows 10以降では、Windows側の「既定のアプリ」設定で他のアプリが明示的に選ばれている拡張子には、Paneの登録が反映されないことがあります。この場合は保存後に表示される案内に従い、Windowsの「既定のアプリ」設定から手動で切り替えてください。

### 既知の制限

- **PNG等の画像形式へのエクスポートには対応していません。** 縦に長い文書を1枚の画像に収めようとすると縦横比が崩れてしまうため取りやめています。同じ用途にはPDFエクスポート(第4.7節)を使ってください。
- **Wordファイル(.docx)の読み込みには対応していません。** 開けるのはMarkdown・テキスト・コードファイルのみです。
- **Word/EPUB/RTF/LaTeX/Textileへのエクスポートは、Pandocというオープンソースの外部ツールに依存しています。** Pandocがインストールされていない環境では、これらの項目はメニュー上でグレーアウトして選べません。
- **多言語対応は未実装です。** 現時点では日本語表示のみに対応しています。

### 外部通信について

使用状況の送信、テーマや辞書のオンラインでの取得、画像アップロードサービスとの連携は、いずれも搭載していません。文書中の`https://`画像も、実体をダウンロードして手元に保存する機能は持たず、参照する形のままです。**書いた内容やファイルの中身が、あなたの手元以外へ送信されることは一切ありません。**

Paneが外部と通信するのは、**新しい版があるかを尋ねるとき**だけです。次の2つの場合に起こります。

1. 設定「バージョン情報」の**「更新を確認」ボタンを押したとき**
2. **起動したあと**（設定「起動時に新しい版があるか確認する」がオンのとき）

どちらも配布元(GitHub)へ「新しい版はありますか」と尋ねるだけで、送るのは問い合わせそのものだけです。**あなたの文書や使用状況は含まれません。**

2 は設定でオフにできます。オフにすると、「更新を確認」ボタンを押したとき以外は通信しなくなります。

新しい版が見つかったときは画面上部でお知らせしますが、**そこで勝手に入れ替えることはありません。** 実際に更新が始まるのは、あなたが「更新する」を押したときだけです。

問い合わせ先は設定ファイル(`updateCheckUrl`)に書かれているほか、設定「バージョン情報」の画面にも表示されるので、どこへ通信するのかをいつでも確認できます。

### 不具合の調査に協力する

設定「バージョン情報」の「ログフォルダを開く」から、動作記録が入ったログファイル(第9章)を確認できます。不具合を報告する際は、発生前後の時間帯のログを添えていただけると調査の助けになります。

ログには、普段は起動・保存・エラーといった節目だけが記録されます。異常があったときは行頭に`[警告]`や`[エラー]`が付くので、その2つを探せば問題の箇所が分かります。Pane自身も起動のたびに前回の記録を読み返していて、前回エラーや警告が出ていた場合はログの冒頭に`[前回の記録]`として件数を残します。

より細かく追いたい場合は、設定「詳細」の「詳細ログを記録する」を有効にしてから、問題の操作をもう一度再現してください。

## 9. データの保存場所

Paneはインストーラを使わない**ポータブルな単一の実行ファイル(`Pane.exe`)**として配布されています。設定・自動保存・ログなどの付随データは、実行ファイルの場所とは別に、Windowsのユーザーごとの領域へ保存されます。

| 内容 | 保存先 |
|---|---|
| 設定(`settings.json`) | `%LOCALAPPDATA%\Pane\settings.json` |
| 自動保存のスナップショット | `%LOCALAPPDATA%\Pane\autosave\` (ウィンドウごとに1ファイル。正常終了時・保存成功時は削除されます) |
| ログ | `%LOCALAPPDATA%\Pane\logs\pane-yyyyMMdd.log` (1日1ファイル) |
| カスタムCSS用のフォルダ | `%LOCALAPPDATA%\Pane\themes\` (書き方の説明が入ったサンプル`sample.css`が自動生成されます) |
| ファイルの関連付け | Windowsのレジストリ(`HKEY_CURRENT_USER\Software\Classes`配下)。管理者権限は不要です |

`%LOCALAPPDATA%`は通常`C:\Users\(ユーザー名)\AppData\Local`を指します。いずれもユーザー権限だけで読み書きできる場所に限られており、`Program Files`のような管理者権限が必要な場所へは書き込みません。

### アンインストール方法

Paneはインストーラを使わないため、専用のアンインストーラはありません。次の手順で片付けられます。

1. ファイルの関連付けを設定している場合は、設定「ファイルの関連付け」からすべてのチェックを外して保存し、登録を解除する
2. コマンドラインからの起動用にPATHへ追加している場合は、設定「詳細」でオフにする
3. `Pane.exe`(および同じフォルダ内のファイル一式)を削除する
4. 必要であれば、上表の`%LOCALAPPDATA%\Pane`フォルダも手動で削除する(設定・自動保存・ログ・カスタムCSSがまとめて消えます)
