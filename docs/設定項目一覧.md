# 設定項目一覧

Paneの設定項目の一次資料。C#側(`Pane/AppSettings.cs`)・ブリッジのJSON・HTML製設定画面
(`src/settings.js`)・実際に効かせる場所(`src/main.js` / `src/editor.js` / C#各サービス)の
4か所で同じキーを使うため、**キー名と取りうる値はこのファイルを正とする**。

Typoraの設定項目は公式のi18nリポジトリ(`typora/Typora-i18n` の `Base.lproj/Panel.strings`)を
一次情報として網羅した。一般的なテキストエディタ(メモ帳・VS Code等)にある項目も併せて拾っている。

## 対象外とした項目

仕様書の「外部通信を一切行わない」方針に反するため、以下は**意図的に実装しない**。

| Typoraの項目 | 対象外の理由 |
| --- | --- |
| Send Anonymous Usage Info | 外部送信 |
| Check updates automatically / Updater | 外部通信 |
| Image Uploader (PicGo / PicList) | 外部アップロード |
| Get Themes / theme.typora.io | 外部ダウンロード |
| Typora Server | 外部通信 |
| ライセンス認証まわり | Paneは認証を持たない |

以下はPaneの設計上そもそも概念が無いため対象外。

| Typoraの項目 | 対象外の理由 |
| --- | --- |
| Window Style (Classic / Seamless / Unibody) | Paneはタイトルバーを持たない単一の外観に統一済み |
| Pandoc Path / LaTeX Engine / PDF Engine 等の詳細 | Pandocは検出のみで、引数の細かい設定は持たない |

## バージョン情報 (versionInfo)

設定値(保存対象)は無く、すべて表示専用の環境情報とボタン。`settings` 応答にのみ含まれ、
`save-settings` では送らない(`draft`には保持するが `buildSavePayload` の対象外)。

| キー | 型・値 | 内容 |
| --- | --- | --- |
| `appVersion` | string | アセンブリのバージョン(取得不可なら「不明」) |
| `webView2Version` | string | WebView2ランタイムのバージョン(未導入等で取得不可なら「不明」) |
| `dotNetVersion` | string | `Environment.Version` |
| `logFolderPath` | string | ログファイルの置き場(`Pane/Logger.cs` の `FilePath` の親フォルダ) |
| `themeFolderPath` | string | カスタムCSSの既定フォルダ(`Pane/ThemeFolderService.cs`) |
| `licenses` | `{ name, license }[]` | Pane本体 + 主要な同梱OSSのライセンス一覧 |
| `settingsFilePath` | string | (既存)設定ファイルの場所。この画面にも表示する |

ボタンとして置くもの(設定値ではない。押すとC#側へメッセージを送るだけで応答は待たない):

- 設定ファイルの場所を開く(`open-settings-file`。既存)
- ログフォルダを開く(`open-log-folder`)
- 今日のログを開く(`open-today-log`)
- カスタムCSSフォルダを開く(`open-theme-folder`。「外観」カテゴリの
  「サンプルのあるフォルダを開く」ボタンと同じメッセージ)

## 送受信の約束

- `apply-settings`(全ウィンドウへ配信): 上記のうち**JS側で効かせる項目のみ**を含める。
  一覧系(`installedFonts` 等)は含めない。
- `settings`(設定画面を開いたときの応答): 上記**すべて**に加えて、
  `installedFonts`(string[])・`monospaceFonts`(string[])・`pandocAvailable`(bool)・
  `settingsFilePath`(string)・上記「バージョン情報」の各キーを含める。
- `save-settings`(設定画面からの保存): 上記すべてを `settings` オブジェクトとして送る。
  C#側は知らないキーを無視し、値の妥当性(列挙値・数値範囲)を検証して不正なら既定値に倒す。
  「バージョン情報」カテゴリの各キーは表示専用のため送らない。
