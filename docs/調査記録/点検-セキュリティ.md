### C-2 SHA256検証の実効性
- [中] `FindZipAsset`(337-368) の SHA256 は GitHub API の asset `digest` から取る。つまり**ハッシュも本体Zipも同じ配布元(GitHub)から同じ経路で来る**。GitHubアカウント/リリースが乗っ取られてZipが差し替えられれば digest もGitHubが差し替え後の値を返すので照合は必ず通る。防げるのは「転送中の破損」と「TLSを破らずにCDN側だけ差し替えられた」ような限定的なケースだけで、配布元侵害・アカウント侵害には無力。加えて `VerifyHash`(436-442) は digest が無ければ照合を省略して続行する(README の「SHA256で照合します」は常に成り立つわけではない)。exe のコード署名検証(Authenticode)も無い。README は改竄防止を明言していないので約束違反ではないが、「SHA256で照合」から利用者が想像する安全性より弱い。対策案: 署名鍵をアプリに埋め込んで署名ファイルを検証する／ハッシュを別経路(別ホスト)から取る／少なくとも digest 無しのときは自動更新せず手動更新へ倒す。
- [低] `Pane/AppSettings.cs:839 UpdateCheckUrl` は settings.json で書き換え可能(画面からは不可: settings.js:2103 表示のみ、SettingsBridge.cs:174 読み取りのみ)。settings.json を書ける＝同一ユーザー権限なので昇格にはならない。TryBuildAtomUrl は api.github.com 以外では null になりAPI直行(UpdateCheckLogic.cs:65)。

### C-7 外部プロセス（Pandoc／既定アプリ／エクスプローラー）
- [確認・問題なし] Pandoc 変換(MainForm.cs:3951-3976)は `ProcessStartInfo.ArgumentList` で `tempMd`, `-o`, `targetPath` を個別に渡す(`UseShellExecute=false`)。文字列連結のコマンドラインは作らないので、ファイル名に空白・引用符・`&` があってもコマンドインジェクションにならない。形式は `docx`/`epub` の固定 switch(3691-3692, 3725-3726)で決まり、JS からの format 文字列が pandoc のオプションになることはない。一時 .md は `%TEMP%\pane-export-{Guid}.md`、終了後削除。
- [中] Pandoc は **パス無しの `"pandoc"`** で起動する(`SettingsBridge.cs:899 DetectPandocAvailable`＝`pandoc --version`、MainForm.cs:3957)。`UseShellExecute=false` の `Process.Start` は Win32 `CreateProcess` に実行ファイル名だけを渡すので、検索順は「1. Pane.exe のあるフォルダ → 2. カレントディレクトリ → 3. System32… → PATH」。すなわち、(1) Pane.exe を置いたフォルダ(README は「好きな場所に置くだけ」と案内しており、ダウンロードフォルダに置く人は多い)、(2) Pane のカレントディレクトリ(関連付けでダブルクリック起動した場合はその文書のあるフォルダになりうる)に `pandoc.exe` という名前のファイルがあれば、本物のPandocより先にそれが実行される。しかも `DetectPandocAvailable` は本体ウィンドウが起動時に JS へ設定を渡す `PostCapabilities`(MainForm.cs:3339、3447行目で呼ぶ。1332行目のメッセージ受信で起動直後に実行)と、設定ウィンドウ用ペイロード(SettingsBridge.cs:182)から呼ばれるため、**エクスポート操作をしなくても、Paneを起動しただけで `pandoc` という名前の実行ファイルが起動する**(プロセス内で1回だけキャッシュ, 890-895行)。現実的な攻撃条件は「zipで受け取ったフォルダ(pandoc.exe 同梱)の中の .md をダブルクリックして Pane を新規起動する」または「ダウンロードフォルダに pandoc.exe を落とさせる」。対策: `PATH` を自前で走査して見つかった絶対パスだけを使う(カレント・exe フォルダは除外)、または Pandoc のパスを設定項目にする。
