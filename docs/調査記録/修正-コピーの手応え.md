# 全文コピーの手応え — チェックマークが一度も表示されていなかった

## きっかけ

利用者から「コピーボタンを押したらコピーできたことが分かるようにアニメーションをつけて」
という要望が出た。アニメーションを足す前に現状を確かめたところ、**そもそも
「コピーしました」のチェックマークが一度も表示されていなかった**ことが分かった。

## 何が起きていたか

右上の全文コピー（`#btn-menu-copyall`）は、コピー前後で2つのSVGを差し替える作りで、
`src/commands.js` が次のように切り替えていた。

```js
idleIcon.hidden = true;   // コピー前のアイコンを隠す
doneIcon.hidden = false;  // チェックマークを出す
```

`hidden` は `HTMLElement` のプロパティで、`SVGElement` には無い。`<svg>` 要素に対する
`svgEl.hidden = false` は、ただのJavaScriptのプロパティを1つ作るだけで、HTMLの
`hidden` **属性** はそのまま残る。したがってブラウザ標準の `[hidden] { display: none }`
が効き続け、チェックマークは `display: none` のままだった。コピー前のアイコンも
`hidden = true` では消えないので、**押しても見た目は何も変わらない**。

計測でも裏が取れた。`.copied` を付けた直後の `<svg class="icon-done">` の
`getComputedStyle(...).display` は `none` のままで、その中の `<path>` に指定した
アニメーションは（描画されない要素なので）1つも開始されていなかった
（`path.getAnimations()` が空、`stroke-dashoffset` が開始値のまま動かない）。

## なぜテストで気づけなかったか

当時の回帰テストは、こう書いてあった。

```js
idle: document.querySelector("#btn-menu-copyall .icon-idle")?.hidden,
done: document.querySelector("#btn-menu-copyall .icon-done")?.hidden,
```

つまり**壊れている当のプロパティを読んで、その値が変わったことを確かめていた**。
`svgEl.hidden = true` は（表示には何の効果も無いが）JSプロパティとしては確かに
`true` になるので、テストは通ってしまう。見た目を確かめるつもりで、実装の内部を
確かめていた。

## どう直したか

タイトルバーのコピー（`#btn-copy`）やコードブロックのコピー（`.cm-code-copy`）は、
どちらも「ボタンにクラスを付け、CSS側が2つのアイコンを出し分ける」形になっていた。
全文コピーもこれに揃えた。

- `src/index.html`: `.icon-done` から `hidden` 属性を外す（JSから外せないため持たせない）
- `src/style.css`: `#btn-menu-copyall .icon-done { display: none }` と
  `.copied` 時の出し分けをCSSで持つ
- `src/commands.js`: `hidden` の付け外しをやめ、`copied` クラスの付け外しだけにする

要望のアニメーションは、そのうえで `copied` クラスに載せた。

- `copy-draw`: チェックマークを線として描き進める（`stroke-dasharray`／`stroke-dashoffset`、260ms）
- `copy-pop`: ボタン全体を一度だけ軽く弾ませる（340ms）

色は既存のホバー／ON表示と同じ `--accent-soft` と `--menu-hover-fg` を使い、ここだけ
新しい色を持ち込まない（仕様書 第10.2節）。コードブロックのコピーボタンにも同じ動きを
付けた。同じ「コピー」で手応えが割れると分かりにくいためである。
動きを控える設定（`prefers-reduced-motion`）ではアニメーションだけを止める。色の変化と
アイコンの差し替えは残るので、コピーできたことは動き無しでも分かる。

連打したときは、クラスをいったん外し、間にレイアウトの読み取りを挟んでから付け直して、
毎回アニメーションをやり直す。外して付け直すだけでは同じフレーム内の変更が1つに
まとめられ、ブラウザが「変化なし」と見なして再生されない。

## テストを直した

`hidden` プロパティではなく、`getComputedStyle(...).display` で**実際に描画されて
いるか**を見るようにした。あわせて `getAnimations()` で、アニメーションが名前だけでなく
**再生中**であることまで確かめる（`.verify-menubar-icons.mjs` の (E)、
`.verify-codecopy-activeline.mjs` の ①(6)）。
